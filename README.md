
# DAVID. | Portfólio Profissional

Portfólio pessoal desenvolvido para apresentar minha trajetória profissional, habilidades técnicas, experiências e projetos na área de Tecnologia da Informação.

## Sobre o projeto

Este projeto foi desenvolvido com o objetivo de construir uma presença profissional na internet, reunindo informações sobre minha formação acadêmica, experiências, competências e projetos.

Sou formado em **Sistemas de Informação pela Universidade Federal Rural da Amazônia (UFRA)** e atuo na área de tecnologia e educação, com experiências em desenvolvimento de software, suporte técnico, robótica educacional e impressão 3D.

## Funcionalidades

- Apresentação profissional.
- Seção sobre mim.
- Exibição de habilidades técnicas.
- Portfólio de projetos.
- Página de contato.
- Layout responsivo para diferentes dispositivos.
- Alternância entre temas claro e escuro.
- Recursos de acessibilidade.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git e GitHub

## Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Execute o arquivo `index.html` utilizando a extensão Live Server ou outro servidor local.

## Objetivo
